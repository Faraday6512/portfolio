Project Value Noise

3D Graphics

Project Overview

This project implements a Value Noise algorithm in C++ to generate procedural textures and visualizes them using OpenGL shaders. Value Noise works by assigning random values to lattice points and smoothly interpolating between them, producing natural-looking patterns used in procedural content generation. The implementation supports 1D, 2D, and 3D noise evaluation with multiple smoothing methods and seamlessly integrates into an existing graphics framework.

Tasks Completed

  • Implemented linear, bilinear, and trilinear interpolation functions as C++ templates in Interpolation.hpp.
  • Implemented the ValueNoise class supporting 1D, 2D, and 3D noise evaluation using permutation hashing.
  • Supported multiple smoothing methods: Linear, Cosine, Smoothstep, and Quintic fade functions.
  • Used a permutation table that is randomly shuffled at construction time to ensure varied noise output.
  • Wrote GLSL shaders (simple.vert / simple.frag) to display generated noise textures with tiling support.
  • Added UploadAsRGBA to the Texture class to efficiently update texture data each frame.
  • Registered the Value Noise demo in the demo factory system.

Reflection

The most challenging part was correctly structuring the trilinear interpolation — mapping 8 lattice corner values to the Near/Far faces and ensuring the hash indices were correctly cast to avoid sign conversion errors. I also encountered linker errors from inline functions defined in headers without the inline keyword, which taught me to be careful about function definitions in header files included across multiple translation units. Overall, this project deepened my understanding of how procedural noise works mathematically and how to bridge C++ template design with GPU-side rendering.
