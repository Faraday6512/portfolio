Project Gradient Noise

3D Graphics

Project Overview

This project implements Perlin-style Gradient Noise entirely in GLSL, rendering the result to an offscreen framebuffer and displaying it either as a 2D texture or as a 3D displaced surface. Gradient noise produces smoother, more natural-looking patterns than value noise by using gradient vectors instead of scalar values at lattice points, making it well-suited for terrain, marble, and wood procedural textures.

Tasks Completed

  • Implemented a 3D Perlin gradient noise function in GLSL using a permutation table (size 64, doubled for wrap-around) and 12 gradient vectors at cube-edge midpoints.
  • Used a quintic fade function (6t⁵ − 15t⁴ + 10t³) and trilinear interpolation (mix) across all 8 lattice corners.
  • Added 5 pattern modes: plain Gradient, Fractal Sum (fBm, 6 octaves), Turbulence (absolute fBm), Marble (sin + turbulence), and Wood (fract).
  • Wrote a surface vertex shader that displaces mesh vertices in the Z direction using the noise texture as a height map.
  • Built the C++ demo class with a framebuffer-based noise generation pass, a spectator camera for the 3D surface view, and ImGui controls for texture size, tiling scale, Z slice, pattern type, and surface geometry.

Reflection

The trickiest part was correctly indexing all 8 lattice corners in the permutation table and keeping the gradient dot-product signs consistent. Debugging noise artifacts required carefully verifying the fade/interpolation math against the reference Perlin paper. Implementing multiple pattern types on top of the same base noise function was straightforward once the core was correct, and seeing the noise drive real-time surface displacement made the result feel immediately tangible.
