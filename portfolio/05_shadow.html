Project Shadow Mapping

3D Graphics

Project Overview

Shadow Mapping is an assignment in CS250 Computer Graphics II at DigiPen Institute of Technology. The goal was to implement real-time shadow rendering using a two-pass shadow mapping technique — first rendering a depth map from the light's perspective, then comparing fragment depths against it in the main pass.

Tasks Completed

  • Created a Framebuffer Object with a depth texture to store the shadow map.
  • Rendered the scene from the light's perspective in a depth-only pass.
  • Transformed fragments into light space and compared depth against the shadow map.
  • Applied a depth bias to eliminate shadow acne.
  • Implemented PCF (Percentage Closer Filtering) for soft shadow edges.
  • Built and deployed a WebGL 2 version using Emscripten.

Reflection

Tuning the depth bias was tricky — too little caused acne, too much caused Peter Panning. Implementing PCF showed me how shadow quality is fundamentally a sampling problem and how a small kernel can dramatically improve edge quality.
